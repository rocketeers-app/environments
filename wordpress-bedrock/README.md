# WordPress (Bedrock)

A [Bedrock](https://roots.io/bedrock/) install: WordPress core and plugins come from Composer,
and `composer.lock` is what Rocketeers detects as WordPress.

The `rocketeers` theme in `web/app/themes/rocketeers` renders the placeholder page. After
`composer install`, activate it with `wp theme activate rocketeers`. The web root is `web/`.
